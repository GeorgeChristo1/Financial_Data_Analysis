# Financial Market Analysis

## Project Overview

This project analyses the performance of four stocks using Python to compare returns, volatility, cumulative performance and correlations.

The objective is to evaluate each stock from both a return and risk perspective and demonstrate how financial data can be analysed using Python.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- JupyterLab

## Analysis Performed

- Data inspection and validation
- Daily percentage returns
- Average daily returns
- Total returns
- Cumulative returns
- Volatility analysis
- Best and worst daily returns
- Correlation analysis
- Stock price visualisation
- Risk vs return analysis

## Key Findings

- Delta generated the highest total return at approximately **31.67%**.
- Delta also had the highest average daily return at approximately **2.02%**.
- Delta had the highest volatility at approximately **2.81%**, demonstrating the trade-off between risk and return.
- Alpha generated a total return of **28%** while experiencing lower volatility than Delta.
- Gamma generated the lowest total return at approximately **14%**.
- Beta and Gamma showed a strong positive correlation in their daily returns.

## Conclusion

The analysis demonstrates that investment performance should not be evaluated using returns alone. Delta produced the strongest returns but also experienced the greatest volatility, while other stocks offered different risk-return characteristics.

The project demonstrates the use of Python for financial data analysis, including return calculations, volatility measurement, correlation analysis and data visualisation.
